# Sobre contas temporariamente banidas

Se você recebeu o aviso "Conta temporariamente banida", é provável que você esteja usando um app não oficial ou esteja coletando dados de usuários, prática conhecida como extração.

Se você recebeu esse aviso, mude para o app oficial ou pare de extrair dados. Caso contrário, sua conta poderá ser banida permanentemente do WhatsApp.

## Sobre apps não oficiais

Os apps não oficiais são apps falsos que imitam o WhatsApp. Por serem desenvolvidos por terceiros, eles violam nossos Termos de Serviço. O WhatsApp não é compatível com esses apps porque não podemos validar as práticas de segurança implementadas por eles. Saiba mais sobre apps não oficiais [neste artigo](https://faq.whatsapp.com/1217634902127718?helpref=faq_content).

## Sobre a extração de dados

A extração é a prática de coletar de dados de maneira automatizada, em pequena ou grande escala, para qualquer fim proibido. Pessoas que praticam a extração de dados tentam encontrar e salvar dados de usuários do WhatsApp. Esses dados incluem números de telefone, fotos do perfil e atualizações de status. A extração de dados de usuários é uma violação dos nossos [Termos de Serviço](https://faq.whatsapp.com/818844662725468?helpref=faq_content). Saiba mais sobre a coleta de dados pessoais [neste artigo](https://faq.whatsapp.com/434518851968943?helpref=faq_content).
